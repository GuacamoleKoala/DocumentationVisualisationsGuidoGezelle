Van Wikidata naar Netwerk

Een 2-uur durende workflow om relaties in erfgoeddata te ontdekken, op te schonen en prachtig te visualiseren.

01

Data Bevragen (SPARQL)

Halen we de ruwe data op uit de Wikidata Query Service. We zoeken naar connecties tussen entiteiten.

example_query.sparql 
SELECT ?item ?itemLabel ?student ?studentLabel WHERE {
  ?item wdt:P106 wd:Q36180 .
  ?student wdt:P1066 ?item .
  SERVICE wikibase:label { 
    bd:serviceParam wikibase:language "nl". 
  }
} LIMIT 100
