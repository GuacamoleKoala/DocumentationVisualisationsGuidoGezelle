Van Wikidata naar Netwerkgrafiek

Welkom bij deze 2 uur durende workshop. We leren hoe we relaties in cultureel erfgoed blootleggen. We vertrekken van Linked Open Data (Wikidata), schonen dit op met AI-tools, en visualiseren de connecties met Gephi.

1

Data Bevragen (SPARQL)

We starten met het ophalen van ruwe data via de Wikidata Query Service. In dit voorbeeld zoeken we naar relaties tussen personen (bijv. leermeester/leerling).

SELECT ?item ?itemLabel ?student ?studentLabel WHERE {
  ?item wdt:P106 wd:Q36180 . # Beroep: Schrijver
  ?student wdt:P1066 ?item . # Student van: ?item
  SERVICE wikibase:label { bd:serviceParam wikibase:language "[AUTO_LANGUAGE],nl". }
}
LIMIT 100
Open Query Service
Leerbron: Wikidata SPARQL Tutorial
