# Netwerkvisualisaties Guido Gezelle op basis van Wikidata

![meemoo logo](https://meemoo.be/docroot/themes/custom/meemoo_theme/logo.svg)

Deze README licht de documentatie toe bij het project omtrent visualisaties rondom beschikbare data op Wikidata inzake het netwerk van Guido Gezelle. 

Dit project werd uitgevoerd door **Jenske Verhamme**, in functie van een stage-opdracht voor de opleiding **'Postgraduaat cultureel erfgoed: digitale transformatie'**.

## 📂 Mappenstructuur: data visualisaties

Hieronder wordt de mappenstructuur verder toegelicht, zodat iedereen hiermee aan de slag kan gaan, indien gewenst:

1. **Query resultaten**: Geëxporteerd vanuit Wikidata Query Service.
2. **Schoongemaakte data**: In Spreadsheets/Excel.
3. **Knopen- en verbindingenbestand**: Geëxporteerd vanuit Spreadsheets/Excel (of uitzonderlijk OpenRefine).
4. **Bestanden in Gephi**: Projectbestanden voor netwerkanalyse.
5. **Sigma export & aanpassingen**: Bestanden na Sigma export en na aanpassingen (soms geen Sigma gebruikt, maar Java, HTML en CSS).
6. **GitHub bestanden**: Bestanden voor de visualisatie (en kopie van repo).
7. **Handleiding van de visualisatie**: Documentatie per visualisatie.
8. **Link naar visualisatie op GitHub**: Directe verwijzingen naar de online versies.
